# 多云对象存储客户端工具技术设计文档

## 1. 技术选型

### 1.1 核心技术栈
- **后端语言**：Go 1.21+（高性能、跨平台、简洁的语法）
- **桌面框架**：Wails 2.0+（Go语言驱动的跨平台桌面应用框架，无需Electron的Chromium实例）
- **页面样式**：TailwindCSS
- **数据库**：SQLite（轻量级本地数据库，用于存储连接配置、操作历史等）

### 1.2 云存储SDK（按厂商分别集成）
- **华为云OBS**：`github.com/huaweicloud/huaweicloud-sdk-go-obs/obs`（v3.27.0+）
- **腾讯云COS**：`github.com/tencentyun/cos-go-sdk-v5`（v0.11.0+）
- **阿里云OSS**：`github.com/aliyun/aliyun-oss-go-sdk/oss`（v2.2.0+）
- **百度云BOS**：`github.com/baiducloud/bce-sdk-go/services/bos`（v0.8.0+）
- **MinIO**：`github.com/minio/minio-go/v7`（v7.0.0+）

### 1.3 前端技术栈（不限制具体实现）
- **框架**：支持现代Web框架（如Vue、React、Svelte等）
- **UI组件库**：支持主流UI组件库（如ArcoDesign、Ant Design、Element Plus等）
- **状态管理**：支持主流状态管理方案
- **构建工具**：Vite 5.0+（快速的前端构建工具）
- **样式方案**：支持CSS Modules、Tailwind CSS等主流样式方案

### 1.4 通信协议
- **Wails Bridge**：前后端通信采用Wails提供的原生桥接机制（高效的进程间通信）
- **WebSocket**：用于实时进度推送和状态更新

### 2.2 核心架构特点
- **原生集成**：Go后端与前端UI通过Wails Bridge直接通信，无需额外的HTTP服务
- **轻量级**：无需Chromium实例，应用体积更小，启动更快
- **高性能**：Go语言处理云存储请求，Wails Bridge提供高效的进程间通信
- **跨平台兼容**：支持Windows、macOS、Linux
- **模块化设计**：各模块职责清晰，便于扩展和维护
- **灵活的前端选择**：支持多种前端技术栈，开发者可根据偏好选择
- **多云存储支持**：通过StorageProvider接口抽象，支持华为OBS、腾讯COS、阿里OSS、百度BOS、MinIO等多种对象存储服务
- **厂商SDK独立实现**：每个云厂商使用各自官方SDK实现，充分利用厂商特有功能和优化

### 2.3 存储抽象层设计

#### 2.3.1 设计原则
- **接口隔离**：定义统一的StorageProvider接口，上层业务逻辑只依赖接口，不依赖具体实现
- **工厂模式**：通过Factory根据连接配置动态创建对应厂商的Provider实例
- **类型安全**：接口返回值使用通用数据结构（如storage.Bucket、storage.Object），禁止返回厂商SDK类型
- **渐进式扩展**：先实现华为OBS作为基准，再逐步添加其他厂商实现

## 3. 核心模块设计

### 3.1 连接管理模块

#### 3.1.1 功能描述
负责多云存储连接的创建、编辑、删除、测试和状态管理，支持华为OBS、腾讯COS、阿里OSS、百度BOS、MinIO等多种存储类型

#### 3.1.2 数据结构
```go
// ProviderType 存储提供商类型
type ProviderType string

const (
    ProviderHuawei ProviderType = "huawei"   // 华为云OBS
    ProviderTencent ProviderType = "tencent" // 腾讯云COS
    ProviderAlibaba ProviderType = "alibaba" // 阿里云OSS
    ProviderBaidu   ProviderType = "baidu"   // 百度云BOS
    ProviderMinIO   ProviderType = "minio"   // MinIO
)

// Connection 连接配置结构体
type Connection struct {
    ID              string    `json:"id" gorm:"primaryKey"`
    Name            string    `json:"name" gorm:"not null"`
    Provider        string    `json:"provider" gorm:"not null"` // 存储提供商类型
    AccessKeyID     string    `json:"accessKeyId" gorm:"not null"`
    SecretAccessKey string    `json:"secretAccessKey" gorm:"not null"`
    Region          string    `json:"region" gorm:"not null"`
    Endpoint        string    `json:"endpoint"`
    Status          string    `json:"status" gorm:"default:'disconnected'"`
    Delimiter       string    `json:"delimiter" gorm:"default:'/'"` // 自定义分隔符
    ExtraConfig     string    `json:"extraConfig"` // JSON格式，存储提供商特有配置
    CreatedAt       time.Time `json:"createdAt"`
    UpdatedAt       time.Time `json:"updatedAt"`
}

// ProviderInfo 提供商信息
type ProviderInfo struct {
    Type        string `json:"type"`
    Name        string `json:"name"`        // 显示名称
    Description string `json:"description"` // 描述
    Icon        string `json:"icon"`        // 图标标识
}
```

#### 3.1.3 核心接口
```go
// 创建连接
func CreateConnection(conn *Connection) error

// 编辑连接
func UpdateConnection(conn *Connection) error

// 删除连接
func DeleteConnection(id string) error

// 获取连接列表
func GetConnections() ([]*Connection, error)

// 测试连接
func TestConnection(conn *Connection) (bool, error)

// 获取连接状态
func GetConnectionStatus(id string) string

// 获取所有支持的存储提供商列表
func GetSupportedProviders() []ProviderInfo
```

### 3.2 StorageProvider接口定义

#### 3.2.1 功能描述
定义统一的存储操作接口，所有云存储厂商实现必须实现此接口，实现应用操作与具体存储服务的解耦

#### 3.2.2 通用数据结构
```go
// Bucket 桶结构（通用）
type Bucket struct {
    Name         string `json:"name"`
    CreationDate string `json:"creationDate"`
    Location     string `json:"location"`
}

// Object 对象结构（通用）
type Object struct {
    Key          string `json:"key"`
    Size         int64  `json:"size"`
    LastModified string `json:"lastModified"`
    StorageClass string `json:"storageClass"`
    ETag         string `json:"eTag"`
}

// ListObjectsResult 对象列表查询结果（通用）
type ListObjectsResult struct {
    Objects []Object `json:"objects"` // 对象列表
    Folders []string `json:"folders"` // 虚拟文件夹列表
}

// ProgressFunc 进度回调函数
type ProgressFunc func(transferred int64, total int64)
```

#### 3.2.3 StorageProvider接口
```go
// StorageProvider 存储提供商接口
type StorageProvider interface {
    // 连接管理
    TestConnection() (bool, error)
    Close()

    // 桶操作
    ListBuckets() ([]Bucket, error)
    CreateBucket(bucketName string) error
    DeleteBucket(bucketName string) error

    // 对象操作
    ListObjects(bucketName, prefix, delimiter string) (*ListObjectsResult, error)
    UploadObject(bucketName, objectKey, localFilePath string, progressFn ProgressFunc) error
    DownloadObject(bucketName, objectKey, localFilePath string, progressFn ProgressFunc) error
    DownloadDirectory(bucketName, prefix, localDir string, progressFn ProgressFunc) error
    DeleteObject(bucketName, objectKey string) error
    CopyObject(srcBucket, srcKey, dstBucket, dstKey string) error
    MoveObject(srcBucket, srcKey, dstBucket, dstKey string) error
    GetObjectContent(bucketName, objectKey string) ([]byte, string, error)
}
```

### 3.5 虚拟文件夹管理模块

#### 3.5.1 功能描述
基于自定义分隔符，将对象Key转换为虚拟文件夹层级，与具体存储提供商无关

#### 3.5.2 核心算法
```go
// ParseObjectKey 将对象Key解析为虚拟路径
func ParseObjectKey(objectKey string, delimiter string) []string {
    if delimiter == "" {
        delimiter = "/"
    }
    return strings.Split(objectKey, delimiter)
}

// VirtualFolder 虚拟文件夹结构体
type VirtualFolder struct {
    Name     string             `json:"name"`
    Path     string             `json:"path"`
    Children []*VirtualFolder   `json:"children,omitempty"`
    Objects  []Object           `json:"objects,omitempty"` // 使用通用Object类型
}
```

## 9. 性能优化

### 9.1 后端优化
- **连接池**：使用连接池管理云存储连接，减少连接创建开销
- **并发处理**：使用Go协程并发处理多个请求
- **缓存机制**：缓存桶列表和对象列表，减少云存储API调用
- **断点续传**：大文件传输采用分片上传/下载，支持断点续传
- **Provider实例复用**：同一连接的Provider实例可复用，避免重复创建

### 9.2 前端优化
- **虚拟滚动**：大量文件列表采用虚拟滚动，只渲染可视区域内容
- **懒加载**：文件夹内容按需加载，减少初始加载时间
- **状态管理优化**：合理设计状态，避免不必要的组件更新
- **Web Workers**：将耗时操作移至Web Workers

### 9.3 数据库优化
- **索引设计**：为常用查询字段创建索引
- **批量操作**：采用批量插入和更新，减少数据库IO
- **定期清理**：定期清理过期的操作历史和临时数据

## 10. 安全性设计

### 10.1 数据加密
- **敏感信息存储**：Access Key ID和Secret Access Key使用AES-256加密存储
- **数据库加密**：SQLite数据库文件加密
- **内存保护**：敏感数据在内存中使用后及时清零

### 10.2 网络安全
- **HTTPS**：所有外部API请求使用HTTPS加密传输
- **请求限流**：防止恶意请求和DOS攻击
- **输入验证**：严格验证所有输入参数，防止注入攻击

### 10.3 代码安全
- **依赖审计**：定期审计第三方依赖，及时更新漏洞修复版本
- **静态代码分析**：使用Go vet、golangci-lint等工具进行静态分析
- **安全编码规范**：遵循Go和前端安全编码规范

## 15. 迁移路线

### 15.1 迁移阶段规划

| 阶段 | 任务 | 产出 |
|------|------|------|
| **Phase 1** | 定义StorageProvider接口和通用数据结构 | `internal/storage/provider.go` |
| **Phase 2** | 扩展Connection模型，添加Provider和ExtraConfig字段 | `internal/connection/model.go` |
| **Phase 3** | 创建Provider工厂函数 | `internal/storage/factory.go` |
| **Phase 4** | 将现有华为OBS客户端改造为Provider接口实现 | `internal/storage/huawei/provider.go` |
| **Phase 5** | 改造app.go，使用StorageProvider接口替代直接调用obs.Client | `internal/app/app.go` |
| **Phase 6** | 实现腾讯云COS Provider | `internal/storage/tencent/provider.go` |
| **Phase 7** | 实现阿里云OSS Provider | `internal/storage/alibaba/provider.go` |
| **Phase 8** | 实现百度云BOS Provider | `internal/storage/baidu/provider.go` |
| **Phase 9** | 实现MinIO Provider | `internal/storage/minio/provider.go` |

### 15.2 兼容性保障
- 现有连接记录的Provider字段为空时，默认兼容为"huawei"
- 数据库迁移时自动补充Provider字段的默认值
- 前端向后兼容，对旧连接自动识别为华为OBS
